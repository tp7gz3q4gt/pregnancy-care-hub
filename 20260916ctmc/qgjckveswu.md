# 战"疫"手记 | 深圳恒生医院杨勇：好的外科医生是内科医生加把刀

> 更新时间：2026-09-16 (UTC+8)

今天（2020年2月20日），**骨科主治医师杨勇**来武汉刚好半个月了。他响应复星医疗集团的征召，2月6日，作为深圳恒生医院医疗小组的领队，杨勇和其他三名恒生医院的医疗队成员一起冲到了武汉抗疫最前线。

临行武汉前，他说：“困难当头，我身为医务人员和党员，有使命，更有责任去。”这句 “请战书”上的誓言，既是他的心声，也是他的承诺和决心。他的妻子是一名护士，默默支持着他的决定；6岁的儿子得知爸爸要上前线战斗，对他说：去吧！儿子还送给爸爸一个口罩和自己珍藏的果冻。

在武汉连续奋战了这些日子，杨勇医生在一线有哪些感触？近日我们小编采访了这位80后医生：

**“好的外科医生是内科医生加把刀”**

**No.1******
您作为一名骨科专业医生，为何要来武汉支援？
杨勇：当时因为武汉疫情严重，我听医院医生说武汉这边很多外科医生都冲到前线去顶门诊了，内科医生在病房里面去管病人，感觉武汉的情况空前紧张，我想我也可以上。我还和我的小孩说，儿子爸爸要去武汉了，我儿子他说，去吧！后来医院征召时，我就写了请战书。我也是名党员，我想党员做任何事都要冲在第一线。我虽然专业是骨科，经常听我的老师说，好的外科医生是内科医生加把刀。因为我日常工作管理的大多数是危重症患者，比如高位颈椎损伤伴四肢瘫的病人，伴有多种基础疾病的脊柱骨折，髋部骨折的老年患者等等，所以我也是具有应对危重病人能力的专业医生。

**No.2******
您一直是从事骨科专业吗？杨勇：我是2012年7月加入深圳恒生医院，担任骨科主治医师一职。此前经历主要和外科相关，2006年毕业之后，当时就到家乡湖南怀化市一家地市级三甲医院进修，学的就是骨科专业。进修完后，应聘到县城一家镇医院。镇医院没有像县级医院或者三甲医院分得那么细，我就是干一个大外科，内科、儿科全部都有。

**No.3******
您穿防护服进传染病病房，是不是头一回？
杨勇：我们是外科医生，对无菌观念是非常强的。外科医生洗手上手术台，都要求无菌操作。所以，包括穿防护服这些都做过培训，很容易理解并在工作中规范执行。

**No.4******
一天穿下来感受如何？

杨勇：最初两天，确实不适应。穿着防护服，戴着N95口罩、防护眼镜，一会眼睛就起雾了，什么都看不清了。然后戴N95口罩压着也很难受，有时候鼻梁都压红了。如果脸上哪个部位痒，又不能去挠啊，很难受，再后来就慢慢适应了。

图说：杨勇（左一）与恒生医院的抗疫医疗队员在一起

**大多数病人对治愈出院充满信心**

**No.5******
您现在武汉一线的工作节奏是怎样的？收治的病人状态如何？

杨勇：现在已经开始轮班了，有白班、连班、夜班，医生轮流有了休息时间。我们目前主要是负责白班和连班。碰到一些危重病人，我们就会一起探讨病情，制定诊疗方案。来了新住院病人，查看病人，开医嘱，书写病例等。这些都需要我们来共同完成。忙的时候一天收7-8个新病人。工作量还是很大的。
病人大多状态都不错，对治愈出院充满信心。近日我就碰到一位患者，因腹痛，诊查核酸阳性后被收治。刚开始患者情绪很激动，说胃痛怎么会住院，怀疑我们误诊。针对患者的疑虑我就反复给他解释，新型冠状病毒感染症状不一定是发热、咳嗽感冒症状，有些人也会表现出腹痛症状。然后再次送核酸检测，查出还是阳性，患者非常沮丧。经过我的安慰、开导后，他焦虑、不安的心绪渐渐地平静了下来，现在正在积极配合治疗中。

**No.6******
能否介绍一下，你们如何通过治疗减少危重病人？
杨勇：记得有一位患者刚进来的时候，指脉氧饱和度测量还可以。但到第二天，查房时看到该患者手指头发紫了，但他自己一点感觉都没有。于是我们立刻测量手指血氧饱和度，结果只有80%多一点。正常人至少要达到95%以上，低于90%以下就是危险信号了。后来我们马上采用医院配置的高流量供氧机对患者进行治疗，缓解了他的病情。很多确诊患者突然出现病情加重，就会出现一些并发症。如果忽视的话，后期抢救就很难了。所以，我们在查房中非常关注患者的各项体征，尤其是指脉氧，也会对他们每天的身体感受进行详细询问。

**No.7******
这段时间，有什么让您感觉特别感动的？
杨勇：济和医院的医务人员真的做得特别好，也非常辛苦。虽然他们从年前一直到现在还没休过假，而且前期医疗物质那么紧缺的条件下，仍然坚持下来了，并且很多病人通过他们的治疗，病情都得到了好转，他们真的很辛苦，也让我们特别感动。

**放弃“铁饭碗”加入恒生医院**

**No.8******
 杨医生，您当时为什么会考虑从湖南怀化去深圳恒生医院工作呢？
杨勇：我是2012年7月份来到深圳恒生医院，到现在差不多七、八年了。当时因为女朋友在深圳工作，为了爱情吧，最终还是放弃了家里的正式编制，来到了深圳恒生医院，一直工作至今。

**No.9******
当时来到深圳，内心有过挣扎吗？
杨勇：有挣扎过，主要是舍不得放弃家里的工作。在老家镇医院工作，按老家的话就是“铁饭碗”，一般能考进编制是很难的。我们当时40多个人争取一个名额，我是以第二名考取的。
来恒生医院工作后，我在深圳结婚生子，安家立业。深圳是沿海城市，知识更新较快，发展机遇多，学习的渠道很多。现在我对恒生产生了深深的感情，尤其是医院加盟复星后，更是坚定了我继续在这里发展的想法。

**No.10******
疫情结束后，您最想做的是什么事？
杨勇：好久没有陪过家人出去旅游了，因为工作原因，一直没有时间，都没有和妻子一起度过蜜月。其实，这也是我觉得最亏欠妻子的一件事，希望这次疫情结束后能弥补上。

**后记：**

采访中，杨勇告诉了一件令他开心的事，他说，2月14日情人节那天，他看到了集团拍摄制作的来自家人的温馨祝福视频时，愣了好长时间。看到家人的问候及祝愿，看到医院对家人的照顾和关心，看见老婆、孩子快乐的样子，心里特别地温暖，满身疲惫也瞬间消失。
他告诉说，来到武汉这些日子，尽管很辛苦、很累，但看到一些病人陆续治愈出院，心里觉得特别欣慰，付出的这些苦和累根本就不算什么。
